제1조 개인정보처리방침의 목적

MamyCare(이하 "서비스")는 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 서비스가 어떤 개인정보를 수집하고, 어떻게 이용·보호하는지 안내합니다.

제5조 개인정보의 제3자 제공

서비스는 이용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 단, 아래의 경우는 예외로 합니다.

  • 이용자가 사전에 동의한 경우
  • 법령에 의거하거나 수사기관의 적법한 요청이 있는 경우

제6조 개인정보 처리 위탁

수탁 업체위탁 업무
Google Firebase (Alphabet Inc.)인증, 데이터베이스, 앱 분석
Anthropic, PBCAI 답변 생성 (질문 내용 처리)

위탁 업체는 위탁 목적 외 개인정보를 이용하지 않으며, 각사의 개인정보처리방침을 따릅니다.

제7조 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 열람 요청: 수집된 개인정보 확인
  • 정정·삭제 요청: 잘못된 정보 수정 또는 삭제
  • 처리 정지 요청: 개인정보 처리 중단 요청
  • 회원 탈퇴: 앱 내 설정 → 내 정보 → 회원 탈퇴

권리 행사는 고객센터 이메일로 요청하거나 앱 내 기능을 통해 직접 처리할 수 있습니다.

제8조 개인정보의 안전성 확보 조치

  • 데이터 전송 시 TLS/HTTPS 암호화 적용
  • Firebase Security Rules를 통한 접근 제어 (본인 데이터만 접근 가능)
  • API 키 및 인증 정보 서버 환경변수 관리
  • 불필요한 개인정보 최소 수집 원칙 준수

제9조 어린이 개인정보 보호

본 서비스는 만 14세 미만 어린이를 대상으로 하지 않습니다. 만 14세 미만 이용자의 회원 가입이 확인될 경우 즉시 해당 계정을 삭제합니다.

제10조 AI 서비스 관련 안내

📌 본 서비스의 AI 에이전트는 입력된 건강 데이터를 Anthropic API로 전송하여 답변을 생성합니다. AI가 생성한 정보는 의료적 진단이 아니며, 건강 이상 시 반드시 담당 의사와 상담하시기 바랍니다.

제11조 개인정보처리방침 변경

본 방침은 법령·서비스 변경에 따라 수정될 수 있습니다. 중요한 변경 사항은 앱 내 공지 또는 이메일로 사전 안내합니다.
